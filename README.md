# 习惯成章

> 应用商店展示名：**习惯成章 · 习惯打卡与日常记录**

习惯成章是一款本地习惯打卡 / 日常记录 / 倒数日应用：支持自由、间隔、定时三种打卡模式与"每次记"，带桌面小组件与本地提醒通知。

> 本仓库只存放**编译好的安装包**，不含源码。

## 安装

### Android

- 文件：`app-release.apk`（签名 release）
- 要求：Android 5.1（API 22）及以上
- 安装：下载后直接打开安装；如系统提示"未知来源"，请在弹窗中允许本次安装来源。更新可直接覆盖（同一签名）。

### iOS

- 文件：`App-unsigned.ipa`（**未签名**）
- 要求：iOS 13.0 及以上
- 安装：未签名包无法直接安装，需使用爱思助手等工具签名后安装（个人免费签名或开发者证书均可）。

## 数据与隐私

- 应用**只在本地运行**：任务、打卡记录、设置等数据仅保存在手机本机。
- 无服务器、不联网、不上传任何数据。
